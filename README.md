# 量潮支付工程档案

支付工程领域的档案——业务计价事实与项目档案，qtcloud-pay 计费模型的直接输入。

## 组织方式

**按业务线分目录，一条计价事实一个文档**：

```
data/profile/
├── README.md            # 本索引
└── qtclass/             # 量潮课堂/实训基地的计价事实
    ├── README.md        # 业务线索引
    ├── earn/            # 代金券发行（挣券渠道）
    └── spend/           # 代金券核销（消费定价）
```

- 目录 = 业务线（qtclass、qtdata、qtcloud……），随业务扩展
- earn/spend 分组：发行与核销对称，是代金券账本的两面
- 文档名 = 计价事实的英文短横线命名

## 与其他层的关系

| 层 | 装什么 | 形态 |
|---|---|---|
| `data/journal/` | 定价规则发布的事件记录 | 时序 |
| `data/insight/` | 建模信号与结构洞察 | 主题 |
| `data/profile/`（本库） | 计价事实本体——计费模型直接输入 | 主题，随规则修订 |
